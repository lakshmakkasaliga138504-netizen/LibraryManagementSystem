# Library Management System

A Java-based Library Management System developed using Advanced Java Technology. The application helps administrators manage students, books, and book issue/return records.

## 🚀 Live Demo

[Open Library Management System](https://librarymanagementsystem-production-06d57591.up.railway.app/index.jsp)

## 🛠️ Technologies Used

- Java 21
- Servlet and JSP
- Spring Framework (Dependency Injection)
- Hibernate ORM
- MySQL
- HTML, CSS and JavaScript
- Apache Tomcat 10.1
- Maven

## ✨ Features

- Admin login and logout
- Student management (Add, View, Update, Delete)
- Book management (Add, View, Update, Delete)
- Issue books to students
- Return issued books
- Track issue and return dates
- Database integration using Hibernate and MySQL
- Session management and authentication

## 🗄️ Database

Database name: `library_management`

Tables:
- `admin_users`
- `students`
- `books`
- `issues`

## ⚙️ Run Locally

1. Install JDK 21, Maven, MySQL and Apache Tomcat 10.1.
2. Create the `library_management` database.
3. Configure database connection settings.
4. Open the project in NetBeans or another Java IDE.
5. Build the project using Maven:
   ```bash
   mvn clean package
   ```
6. Deploy the generated WAR file to Tomcat.
7. Open the application in your browser.

## ☁️ Deployment

The application is deployed using Railway with a MySQL database.
